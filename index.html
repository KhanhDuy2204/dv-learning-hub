Project cuối khóa

Project 1 — Mạch đếm đồng bộ

Thiết kế bộ đếm đồng bộ có ngõ vào clock, reset, enable và các ngõ ra trạng thái.

  • Vẽ sơ đồ khối.
  • Lập bảng trạng thái.
  • Thiết kế bằng flip-flop.
  • Viết code Verilog.
  • Tạo testbench và kiểm tra waveform.

Project 2 — FSM điều khiển cửa

Thiết kế FSM điều khiển hệ thống mở khóa cửa bằng chuỗi tín hiệu đầu vào.

  • Xác định các trạng thái.
  • Vẽ sơ đồ chuyển trạng thái.
  • Lập bảng mã hóa trạng thái.
  • Viết FSM Moore hoặc Mealy.
  • Kiểm tra các chuỗi đúng và sai.

Project 3 — Verification bằng SystemVerilog

Xây dựng testbench có transaction, driver, monitor, scoreboard và coverage.

Project 4 — Bộ xử lý đơn giản

Thiết kế CPU nhỏ gồm register file, ALU, control unit và bộ nhớ.
